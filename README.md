# Xiaoguo's Axe

一把比下界合金斧更强、自带火焰附加和横扫之刃的远古双头战斧。

## 功能特性

- 🪓 攻击伤害：25（1 基础 + 4 材料加成 + 20 额外加成，下界合金斧为 10）
- 🔥 自带火焰附加 III（高于原版满级 II，灼烧时长按等级生效）
- ⚔️ 自带横扫之刃 I（原版仅剑可用，本斧直接写入组件，不受限制）
- 🛡️ 耐久度：8192（下界合金斧的 4 倍）
- 🔥 耐火属性（不会在火焰或熔岩中消失）
