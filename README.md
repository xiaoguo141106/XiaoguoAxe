# Xiaoguo's Axe

一把比下界合金斧更强、自带火焰附加和横扫之刃的远古双头战斧。

## 功能特性

- 🪓 攻击伤害：14（比下界合金斧高 4 点）
- 🔥 自带火焰附加 II（攻击使目标燃烧 3 秒）
- ⚔️ 自带横扫之刃 III
- 🛡️ 耐久度：8192（下界合金斧的 4 倍）
- 🔥 耐火属性（不会在火焰或熔岩中消失）
